PROTOCOL MAP

        
目的から選ぶ

      

      

        
SECRET
Password / TOTP
知識・共有秘密で本人確認。保管とreplay対策が中心。
salt · KDF · counter

        
DELEGATION
OAuth / OIDC
API権限の委譲と、認証イベントのフェデレーション。
state · PKCE · nonce · aud

        
HIGH SECURITY
FAPI 2.0
PAR/JAR/JARM/RAR/CIBAとsender constraintを、SecurityとMessage Signingに分離。
request_uri · JWS · auth_req_id

        
FEDERATION
SAML
企業IdPとSPのブラウザSSO。署名対象XMLとmetadataを信頼。
issuer · ACS · audience

        
TICKETS
Kerberos
KDCが短寿命ticketを発行し、組織内SSOを実現。
TGT · service · authenticator

        
PUBLIC KEY
WebAuthn
origin/RPに束縛された公開鍵credential。phishing耐性。
challenge · rpIdHash · UV

        
POSSESSION
mTLS / DPoP
tokenを証明書または公開鍵へ束縛し、単純replayを狭める。
x5t · jkt · htm · htu

        
LIFECYCLE
LDAP / SCIM
directory検索とアカウントprovision/deprovision。
bind · filter · PATCH · ETag

        
DECISION
RBAC / ABAC / ReBAC
主体・操作・対象・文脈から、デフォルト拒否で判断。
role · attribute · relation
