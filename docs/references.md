# 公式仕様・推奨資料

仕様は更新されます。実装時は、ライブラリのドキュメントだけでなく、発行元の最新版と
security considerationsを確認してください。

- [Device Authorization Grant — RFC 8628](https://www.rfc-editor.org/rfc/rfc8628)
- [Token Introspection — RFC 7662](https://www.rfc-editor.org/rfc/rfc7662)
- [Token Revocation — RFC 7009](https://www.rfc-editor.org/rfc/rfc7009)

- [DPoP — RFC 9449](https://www.rfc-editor.org/rfc/rfc9449)
- [JWT — RFC 7519](https://www.rfc-editor.org/rfc/rfc7519)
- [JWS — RFC 7515](https://www.rfc-editor.org/rfc/rfc7515)

- [FAPI 2.0 Security Profile](https://openid.net/specs/fapi-security-profile-2_0-final.html)
- [FAPI 2.0 Message Signing](https://openid.net/specs/fapi-2_0-message-signing.html)
- [OAuth 2.1 project status](https://oauth.net/2.1/)

OAuth 2.1はOAuth 2.0の安全な実務プロファイルを統合する進行中の仕様です。現在の
システムでは、OAuth 2.0とSecurity BCPを基準に、利用するプロファイルを明記します。
