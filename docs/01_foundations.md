# 01 - 土台: パスワード・MFA・セッション

> 実装: `authlab/passwords/`, `authlab/mfa/` / ドリル: `drills/01_passwords.py`, `drills/02_mfa_totp.py`

## パスワード保存の4原則

破られる頻度が高い順:

1. **パスワードそのものを保存しない**。一方向関数の結果だけを保存する。
2. **ユーザごとに salt**。salt がないと、同じパスワードが同じハッシュになり、
   1つのレインボーテーブルでDB全体が一気に割れ、さらに「誰と誰が同じパスワードか」が
   カラムを見るだけで分かってしまう。
3. **わざと遅くする**。SHA-256 は GPU で毎秒数十億回試せる。scrypt / Argon2 は
   **メモリコスト**を足す。これが GPU/ASIC に効く（コアは数千あっても、独立した
   高速メモリは数千MBも無いから）。
4. **パラメータをハッシュと一緒に保存する**。2015年に妥当だったコストは今は不十分。
   パラメータがハッシュ文字列に入っていれば、コストを上げて、次回ログイン成功時に
   透過的に再ハッシュできる。

auth-lab は PHC 風の自己記述文字列で保存する:

```
$scrypt$n=16384,r=8,p=1$<salt-b64u>$<hash-b64u>
```

この形式なら、検証側は「今日のデフォルト」を仮定せず、保存値からアルゴリズムとコストを
読み取れる。これが原則4を可能にする。

### ユーザ列挙対策（タイミング）

素朴なログインは「存在しないユーザ」なら即座に返り、「パスワード間違い」なら
~50ms かかる。この差でユーザ名を列挙できる。`fake_verify` は存在しないユーザに対しても
本物と同じ時間を消費する（`authlab/passwords/hasher.py`）。

### pepper

DB の外（環境変数・KMS・HSM）に置く秘密を、ハッシュ前に HMAC で混ぜる。DB ダンプ
だけではオフライン攻撃が成立しなくなる。ただし pepper のローテーションは全ハッシュを
無効化するので、あくまで多層防御であり KDF の代わりではない。

## MFA: TOTP / HOTP

- **HOTP (RFC 4226)**: `HMAC-SHA1(secret, counter)` の動的トランケーション。4行で終わる。
- **TOTP (RFC 6238)**: counter を `floor(now/30)` に置き換えただけ。

TOTP で難しいのは暗号ではなく運用:

- **クロックドリフト**: ±1ステップ(=90秒)の許容が普通。1ステップ増やすごとに攻撃者の
  当たる確率も同じ倍率で上がる。
- **リプレイ**: コードは1ステップ有効なので、フィッシングされたコードはその窓内で再利用
  できる。**サーバは最後に受理したステップを記憶し、それ以下を拒否しなければならない**。
  自作 TOTP で一番よく抜ける実装。auth-lab は `TOTP.last_step` で防ぐ。
- **秘密の管理**: 共有秘密は対称鍵。持つ者は永久にコードを作れる。コードを一度フィッシング
  されるのは耐えられるが、秘密を漏らすのは致命的。これが WebAuthn/passkey が構造的に
  TOTP に勝つ理由（共有秘密が存在せず、署名がオリジンに束縛される）。

### リカバリコード

MFA を迂回できる bearer 資格情報なので、パスワード並みに扱う: CSPRNG 生成・ハッシュ保存・
単回使用・登録時に一度だけ表示。高エントロピー（80bit）なので遅い KDF は不要だが salt はする。

## セッション管理（設計指針）

- セッション ID は 128bit 以上、CSPRNG（`secrets`、`random` は不可）。
- Cookie は `HttpOnly`（JS から読めない）, `Secure`, `SameSite`。
- トークンは JS から読める場所（localStorage）に置かない。XSS 1つで全アカウント恒久乗っ取り。
  ブラウザアプリなら「httpOnly Cookie にセッション ID、トークンはサーバ側」（BFF パターン）。
- ログイン成功時にセッション ID を再生成（セッション固定攻撃対策）。

## 一言で

**salt でレインボーテーブルを潰し、遅い memory-hard KDF で総当たりを潰し、
パラメータ埋め込みでコスト更新を可能にし、定数時間比較で列挙を潰す。**
