# Security policy

## Educational scope

`authlab/` intentionally reimplements selected cryptographic and protocol
mechanisms so learners can inspect them. It is not a production authentication
library and must not protect real accounts, credentials, payments, or personal
data.

## Reporting

Do not open a public issue for a vulnerability that could affect users of a
deployed system. Use GitHub's private vulnerability reporting feature on the
repository Security tab. For correctness problems limited to this educational
implementation, a normal bug issue is appropriate if it contains no real
secret, personal data, or live target.

## Supported version

Only the latest commit on the default branch is maintained.
